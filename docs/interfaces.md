# 界面设计

设计开始菜单、对话框、暂停菜单，以及游戏中弹出的属性和设置页面。

![选中对话框后，用八向手柄调整尺寸，在右侧修改样式](../assets/docs/interfaces.jpg)

## 选择页面与控件

左边是页面列表。点开页面后，继续选择它下面的按钮、文本和其他控件。示例已有“开始”“对话”“暂停”“属性”“设置”“对话历史”，可以直接修改。

点击加号新建页面。右边选择它是覆盖整个画面的“基础界面”，还是叠加在现有画面上的“弹出界面”。

## 添加一个控件

![展开顶部“控件”菜单，选择需要的类型](../assets/docs/controls.jpg)

| 控件 | 可以用来做什么 |
| --- | --- |
| 文本 | 标题、说明、体力数字、人物好感。 |
| 按钮 | 开始游戏、打开菜单、触发剧情。 |
| 图片、面板 | 装饰图、底图、分组底板。 |
| 进度条 | 显示体力、经验、练习进度。 |
| 滑条、开关、输入框 | 调整数值、切换状态、填写内容。 |
| 对话历史 | 回看当前游戏中的对白。 |

添加后在画布上拖动，右侧可以修改文字、颜色、图片、尺寸和其他属性。

## 摆放与缩放

拖动控件改变位置，四边手柄改变宽高，四角按比例缩放。靠近中心时会吸附，也可以用工具栏的水平、垂直居中按钮。

方向键可以小幅移动，按住 Shift 移动更快；拖动时按住 Alt 可暂时关闭吸附。加减按钮只缩放编辑视图，便于处理细节。

## 修改对话框

对话框由背景、人物姓名和对白文字组成。在左边分别选中它们，再移动或改变尺寸。先调整大对话框，再处理姓名和文字留白。

用“背景图片”替换底图。透明装饰图可以保留形状，但文字区域要有清晰底色。预览时检查长句换行，避免姓名遮住正文。

## 给控件换上图片

按钮可以使用图片背景，也能分别设置鼠标经过、按下和禁用图片。只保留图案的按钮，可以将文字留空。

开关能设置开启、关闭图片；进度条和滑条能设置背景、填充图片。未上传图片的部分使用颜色。

## 让按钮和数值起作用

选中按钮，在右侧选择点击后的动作，再从目标列表选择剧本或页面。例如“调用剧本”触发一次练习，“打开弹窗”显示属性面板。

体力条同时选择当前体力和最大体力；文本显示已创建的数值；滑条、开关和输入框可以关联相应变量。先在“项目设置”准备好，再回来选择。

不熟悉时，可以直接描述想法：

```prompt
在属性页加一个体力条，显示当前体力和最大体力；再放一个“练习一次”按钮，点击后执行练习剧情。
```

这里专门用来排版，不会执行按钮、播放音乐或推进故事。完成后到“预览”实际点击和游玩。对话框位置、字体和样式修改后，切回预览会同步更新并保留当前剧情进度；修改剧本流程后应重新开始测试。
