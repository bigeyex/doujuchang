# 预览与测试

把自己当作第一次看到故事的玩家，从开场走到选择，再走到结局。

![左边是游戏，右边显示当前测试的变量与执行位置](../assets/docs/preview.jpg)

## 开始与停止

点击右上角三角形开始，点击方形停止。想重玩时先停止，再播放。只检查某一段，可以使用“预览当前剧本”或剧本列表里的快捷播放按钮。

逐字显示对白时，第一次点击显示完整句子，再点进入下一句。有选项时点选项；播放演出时等待结束，允许跳过的视频可以点击跳过。

## 检查不同选择

右边是这一局测试的当前数值。临时改变信任值或证据状态，观察选项、台词、属性显示是否跟着变化。

这些改动不影响新游戏默认值。固定修改初始体力等内容，应回到“项目设置”。

暂停执行后可以使用单步查看剧情如何继续；右边的执行位置帮助你回到相应剧本。

## 回看对白与存档

示例顶部和暂停菜单都有“历史”入口。打开后滚动查看已说过的对白，关闭时回到原来的句子。

存档保留当时进度和对白历史。先存一次，再推进几句，读档后检查是否回到原位。大幅修改故事后，建议重新开始测试。

## 导出前检查一遍

- 从开始菜单进入，走到每个结局。
- 选择能到达预期位置，不会意外进入另一分支。
- 表情切换不跳动，背景完整覆盖画面。
- 长句、姓名和选项清楚，历史与暂停菜单能关闭。
- 音量合适，音效和视频不会意外打断节奏。

底部提示问题时，点击查看，再回到剧本修正。看不懂提示，可以告诉豆包工作当前现象，让它帮你定位。
