# 使用指南

编辑器里的每个页面负责一类创作。从示例直接改起，想做哪一部分，就打开对应章节。

## 每个页面怎么用

![编辑器通常由左侧列表、中间创作区、右侧属性组成](../assets/docs/script.jpg)

先在顶部选页面，再在左边选对象，在中间操作，最后到右边调整细节。“（可选）”表示可以先不填，沿用默认效果。

| --- | --- |
| 写对白、加分支、安排演出 | [撰写剧本](writing-story.md) |
| 导入半身立绘、对齐表情、生成新立绘 | [人物与立绘](characters.md) |
| 换场景、移动和缩放背景 | [背景](backgrounds.md) |

| 摆放菜单、对话框、按钮和属性条 | [界面设计](interfaces.md) |

## 保存与继续创作

修改会自动保存，底部会显示保存状态。关闭前等到“已保存”。下次告诉豆包工作“继续编辑我的《作品名》”，让它打开原来的作品。

把作品保留在固定项目空间中。要换电脑或请朋友接手，可以让豆包工作整理并复制整个作品；只有导出的游戏包，不一定足够继续编辑。

你和豆包工作都可能修改同一段内容。若提示内容冲突，先比较两边的修改，再决定保留哪一份，避免直接覆盖尚未保存的文字。

## 怎样和豆包工作配合

描述你想看到的变化，最好指定人物、场景或页面。例如：

```prompt
给林夏增加一个惊讶表情，保持校服、发型和现有半身构图一致。
```

```prompt
让“公开记录”和“先听解释”有不同代价，并保留一个能和解的结局。
```

```prompt
把暂停菜单的按钮排得更紧凑一些，并在预览中让我检查效果。
```

也可以完全自己编辑。建议一次改一小段，随手预览，确认效果后再继续。
