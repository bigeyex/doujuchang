# 项目设置

决定作品名称、横竖屏、开始时使用的页面，以及故事需要记住的数值。

![画面设置可以切换横竖屏和参考尺寸](../assets/docs/settings.jpg)

## 选择横屏或竖屏

打开“项目设置”，左边选择“画面”，点击“竖屏”或“横屏”。默认是竖屏。

没有特殊需求时，保留参考尺寸即可。切换方向后，到“背景”和“界面”检查取景与按钮位置，再用“预览”看一次。

## 添加故事需要记住的内容

左边选择“变量”。变量可以是数字、是或否的状态，或一段文字。例如体力、是否找到证据、玩家姓名。

添加时起一个容易记住的名字，选择类型，设置游戏开始时的默认值。示例已有体力、信任值、证据状态，可以先直接使用。

这里改的是每次新游戏的起始值；预览中临时改的值只影响当前测试。想让所有新游戏从 50 点体力开始，就在这里修改默认值。

## 作品名称和默认页面

左边选择“项目”，修改作品名称，选择开始页和默认游戏页。示例页面已经连接好，刚上手时保留它们，先修改页面内容。

属性中的标识符用于让作品找到同一个对象，与显示名称不同。只想改玩家看到的文字，修改名称即可。
