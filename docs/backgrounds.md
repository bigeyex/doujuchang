# 背景

背景决定故事发生在哪里。导入图片后，在画布上移动、缩放，决定玩家看见的部分。

![背景画布的八个手柄用于调整图片，画面外的部分会被裁掉](../assets/docs/backgrounds.jpg)

## 导入和替换

打开“背景”，点击左侧列表上方的加号选择图片，再给场景起一个容易辨认的名字，例如“雨后的走廊”。

替换已有场景时，先选中它，再点击中间工具栏的“替换图片”，之后检查是否完整覆盖画面。

## 调整取景

- 拖动图片，把重要物体放到合适位置。
- 拖动边缘手柄改变大小，四角手柄保持图片比例。
- 超出游戏画面边界的部分会被裁剪，玩家看不到。
- 用画布上方的加减按钮缩放工作区；点击百分比按钮可以适合画布。

工作区缩放只影响编辑时看得多大。要改变游戏里的背景大小，应拖动图片手柄。

竖屏通常只显示宽图片的一部分。先把主体放到画面里，再适当放大覆盖边缘。切换横竖屏后，重新检查取景。

## 选择转场

右侧设置默认转场和时长。“淡入淡出”让新背景逐渐出现，“无”会直接切换。

回到“剧本”添加“背景”演出，选择刚才的场景。某一次需要不同效果时，可以在剧本背景表单中单独调整。
