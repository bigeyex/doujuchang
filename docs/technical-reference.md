## 选择正确的文件

**修改作品**：编辑作品目录中的剧本、配置与素材，或使用可视化编辑器。无需修改工具源码，也无需重建 Cocos 播放器。

**修改工具**：下载 [source.zip](../source.zip)，在独立目录安装开发依赖。编辑器修改和播放器修改走不同构建步骤，见[源码与构建](development.md)。

**运行工具**：[skill.zip](../skill.zip) 已包含编辑器、Node 启动服务和 Cocos Web 播放器。需要 Node.js 22+，不需要安装 npm 依赖或 Cocos Creator。
