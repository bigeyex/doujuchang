# 撰写剧本

先写人物说什么，再安排他们在哪里、以什么表情出现。右边的指令面板可以替你填写演出，不必一开始就记住所有写法。

## 选中一幕，开始写

![剧本列表、文字编辑区与指令面板](../assets/docs/script.jpg)

左边是剧本列表，点击切换。点击上方加号新建；拖动改变顺序。排在第一项、带 main 标记的剧本是游戏入口。其他剧本需要由故事主动转过去，不会按排列顺序自动播放。

在中间修改对白。点击右边的人物名称，会新起一行该人物的对白，接着写内容即可。普通文字行会作为旁白。

修改错了可以撤销；需要批量调整措辞时可使用查找替换。只想看当前一幕，点击“预览当前剧本”，或把鼠标放在左侧剧本上，点击出现的播放按钮。

## 用面板添加演出

![添加背景时，先选择场景和转场，再确认插入](../assets/docs/script-command.jpg)

1. 把文字光标放到准备添加演出的位置。
2. 在右边点击“背景”“立绘”“动画”等按钮。
3. 选择素材与效果，填好需要的内容。
4. 点击“添加指令”，演出会插入剧本。

立绘先选“替换”“增加”或“隐藏”，再选人物、表情与位置。同一个人物再次出现时会使用新的立绘。左右位置各有槽位：相同位置、相同槽位会替换，使用不同槽位可以让多个人留在同一侧。

光标移进已有指令后，右边会显示它的属性。改完点击“应用”，调整原来的演出。

## 给玩家一个选择

点击右边“选项”，依次添加选项文字和去向。每项都可以删除，或通过拖动、上下箭头重新排序。先准备好各个去向的剧本或故事位置。点击“目标”后，可以输入剧本名、标签名或完整目标筛选，再点击结果或用上下键和回车选择。

例如给出“先听解释”和“公开记录”，分别进入不同对话。需要显示人物好感或体力时，用文字旁的变量菜单插入数值。

写第一幕时，做到这里已经足够。下面介绍编辑区中这些文字的规律，方便直接写、复制或调整整段故事。

## 读懂剧本的写法

一行普通文字是一句旁白。人物代号后面加冒号，是这个人物的对白；中文项目可直接使用人物的中文标识符，例如林夏和陈默。

```avg
放学后的走廊，只剩下两个人。
林夏: 先别急，我们把事情弄清楚。
陈默: 好，我从头说。
```

方括号里的内容安排演出。一条指令单独放一行，常用资源名和目标不需要双引号。下面的人物和背景都存在于内置示例里：

```avg
[背景 放学后的走廊 转场=淡入淡出 时长=0.4]
[显示 林夏 表情=默认 位置=左侧]
林夏: 节目单上为什么没有我们班？
[显示 陈默 表情=默认 位置=右侧]
陈默: 我也在等一个解释。
```

这些代号可以在素材或剧本的属性里看到。写错代号时，底部检查提示会指出问题。还不熟悉时，用右侧面板选择素材，让编辑器替你填入。

| 想做的事 | 写法 |
| --- | --- |
| 换背景 | `[背景 广播室]` |
| 显示人物 | `[显示 林夏 位置=左侧]` |
| 隐藏一个人／所有人 | `[隐藏 林夏]` ／ `[隐藏]` |
| 让人物抖动 | `[动画 林夏 动画=抖动 时长=0.3]` |
| 播放音效／背景音乐 | `[音效 bell]` ／ `[音乐 你的音乐代号]` |
| 等待一会 | `[等待 时长=1]` |
| 结束故事 | `[结束]` |

## 条件、数值与变量文字

变量用于记住玩家的选择，例如“是否找到证据”“信任值”“体力”。先到“项目设置”的“变量”页添加，再在剧本使用。示例已经有 找到证据（是否找到证据）、信任值（信任值）和 属性.体力（体力）。

```avg
[设置 信任值 += 1]
林夏: 我愿意再相信你一次。现在的信任值是 {信任值}。
[如果 找到证据]
  林夏: 我们有记录可以核对。
[否则]
  林夏: 先去广播室问问吧。
[/如果]
```

花括号会显示当时的数值，选项文字里也能用。“如果”和结束的“/如果”要成对出现，中间可以加“否则”。

## 跳到另一段，或借用一段情节

“跳转”去新位置继续故事；“调用”先去执行一段内容，遇到“返回”后接着当前故事。

```avg
[调用 广播室2]
林夏: 广播室问过了，现在做决定吧。
[跳转 最后的选择]
```

这里 广播室2 是示例的“广播室”，最后的选择 是“最后的选择”。同一剧本里的位置可以用“标签”命名，跳转时在名称前加井号。

## 一个可以试玩的分支案例

以下片段使用内置示例的人物和背景。可以让豆包工作把它放进新剧本，再用“预览当前剧本”试玩。

```avg
[背景 放学后的走廊]
[显示 林夏 位置=左侧]
林夏: 我想先听你解释。你呢？
[选择]
  [选项 文本=先听解释 目标=#倾听]
  [选项 文本=公开记录 目标=#记录]
[/选择]

[标签 倾听]
[设置 信任值 += 1]
林夏: 好，你从头说。我听着。
当前信任值：{信任值}。
[结束]

[标签 记录]
[显示 林夏 表情=生气 位置=左侧]
林夏: 把记录公开吧，别让大家继续猜。
[结束]
```

“选择”里放各个“选项”，每个选项指定去向。两个分支最后分别结束，避免顺着文字继续进入另一个分支。

## 重复情节与写作备注

需要重复练习或消耗体力时可以用循环。这个例子每次减少 10 点体力，每句对白仍等待点击，体力不足就退出循环。

```avg
[循环 属性.体力 >= 10]
  林夏: 再练一次。
  [设置 属性.体力 -= 10]
[/循环]
林夏: 今天就到这里吧。
```

写给自己的备注放在多行注释中，游戏会略过它：

```avg
/* 留一段停顿，
   等人物情绪缓下来再继续。 */
[等待 时长=1]
```

输入左方括号时会出现补全。“背景”、拼音“beijing”、首字母“bj”或英文“background”，都能找到背景指令。中文和英文写法可以混用。

需要查询全部参数和复杂用法时，再看[详细脚本格式](script-system.md)。
