# Agent AVG 创作工具设计讨论稿

状态：产品设计规范。首版实现、验证范围及后续功能见 implementation.md；引擎固定为 Cocos Creator 3.8.8。

## 1. 产品与文件

这是一个供 Agent 与用户协作构建文字冒险游戏的 skill 工具包。Skill 指导创作、调用工具与验证；Web 编辑器让用户直接修改作品；内置 Cocos 运行时执行游戏。

- 用户通过 Agent 对话描述意图，也可以直接编辑 Web 界面。
- Agent 和编辑器共用项目源文件，编辑器监听外部修改。
- 剧本保存为 UTF-8 文本，人物、背景、界面、变量等保存为结构化数据，素材为普通文件。
- 资源使用稳定 ID，显示名称、文件路径可以独立修改。
- 编辑器自动保存，使用文件版本检查避免覆盖外部修改；冲突保留双方版本供选择。
- 页面刷新不丢失已保存项目。撤销、选中项、面板宽度等编辑器状态与游戏数据分别保存。
- Skill 的公共工具接口围绕创建、启动、检查、构建和导出，不绑定某个 Agent 的私有浏览器协议。各 Agent 的本地服务与文件访问能力需要单独验证。

## 2. 公共布局

顶部左侧：剧本 / 人物 / 背景 / 界面 / 项目设置 / 预览。

顶部右侧：播放图标 / 停止图标 / 导出。

- 顶部播放从 main 启动一个全新测试会话，并切到预览页；已有会话时相当于重新开始。
- 停止结束测试会话，并返回启动前的编辑页、选中项和光标位置。
- 预览标签只切换页面，不自行重启游戏。
- 人物、背景、界面页内的演出试听不启动剧情，也不更改全局游戏会话。
- 播放与停止通过可用状态、图标和 tooltip 表达，不附加常驻说明。
- 导出打开简洁的格式选择面板，进度、错误只在实际发生时出现。
- 项目默认竖屏，在独立的“项目设置”页面切换横屏。所有编辑器与导出读取同一套项目画幅配置。
- 不设置欢迎横幅、重复标题、常驻教程、宣传文案和无意义的 secondary text。
- 表单保留必要字段名称；复杂字段按需显示 tooltip；输入错误就在字段旁呈现。

剧本、人物、背景、界面遵循“左列表 / 中创作区 / 右属性区”。左右栏可以拖动宽度并收起。窄空间优先保留创作区：属性栏可切换为覆盖抽屉，列表通过按钮展开。面板切换保留各自选择与滚动位置。

预览采用“左游戏 / 右调试栏”的两栏布局，游戏区占剩余空间。右栏可以收起。

## 3. 剧本

### 左侧

- 顶部仅保留新建、搜索等必要工具；较少使用的操作进入菜单。
- 剧本行显示名称；第一项显示紧凑的 main 标记。
- 初始创建一个名为 main 的脚本。main 是列表首项的入口角色，不是固定文件名。
- 拖动手柄上下排序；顺序持久化。拖动完成后第一项立即成为 main。
- 重排不改脚本 ID，不改既有 jump/call 引用，不影响正在运行会话的入口快照；下次启动使用新顺序。
- 列表顺序不表示自动连续执行。第一项以外的脚本通过显式 jump/call 到达。
- hover 或键盘聚焦时出现快速预览图标；图标点击不触发拖动，也不移动文本光标。
- 快速预览建立独立测试会话，由内部测试入口 call 所选脚本，切到预览页；使用项目默认变量或选定测试预设，不执行 main 的前置逻辑。脚本 return 后测试正常结束，因此可直接测试可返回片段。
- 第一版仅支持全局变量，不提供调用参数和局部变量；依赖特定变量或场景状态的片段可保存测试预设。
- 空项目显示一个新建入口；没有脚本时播放不可用。删除首项后剩余第一项成为 main；删除仍被引用的脚本需要处理引用。

### 中间

- 采用轻量文本编辑器，建议 CodeMirror 6；选型留待实现确认。
- 支持语法高亮、标签与属性补全、资源和标签跳转补全、查找替换、折叠、撤销重做与错误定位。
- 对白直接书写，指令使用方括号标签；规范见 [script-system.md](script-system.md)。
- 下拉补全显示资源名称和必要缩略图，实际写入稳定 ID。
- 诊断直接显示在对应位置；只在需要时展开问题列表。
- 剧情执行位置可以高亮，调试信息可以点击返回源码。
- 不对每次表单修改重新格式化全文；保留注释、空行和用户排版。

### 右侧

普通文本状态：标签工具在上，项目人物列表在下。

- 标签入口使用简短按钮：背景、立绘、隐藏、对白、选项、条件、循环、变量、跳转、调用、返回、动画、音乐、音效、等待、弹窗、切换界面、关闭弹窗。
- 光标进入标签后，上方显示当前标签属性；添加入口保持紧凑，人物列表仍可访问。
- 未完成、暂时无法解析的标签保留在文本中，面板不猜测并重写错误范围。
- 表单修改精确作用于当前标签的对应参数，作为一次可撤销编辑。
- 人物行 hover/聚焦显示“动画 / 显示 / 隐藏”；触屏通过菜单访问。
- 点击显示，右栏临时切到该人物立绘列表，顶部为返回按钮；选择后插入 show，可设置左中右位置。
- 取消素材选择不插入内容，恢复此前光标、滚动和面板。
- 点击动画进入带人物上下文的动画选择与参数面板。
- 隐藏面板默认隐藏全部，也可选择角色；一个角色只显示一张立绘，没有实例属性。
- 修改当前 show 的立绘字段会替换参数；从人物快捷操作进入则插入新指令。
- 选择器打开时记录文档版本及插入锚点；若期间外部修改使目标不再明确，提示重新选择插入位置。

## 4. 人物

### 左侧

- 人物列表：自动裁切的小头像与名称；顶部新建、导入、搜索。
- 没有单独的头像素材或头像上传入口。头像从该人物第一张立绘的脸部中心区域自动生成。
- hover 显示操作菜单，支持复制和删除；删除前展示仍存在的引用。
- 选中人物后，中间和右栏同步切换，不启动故事。

### 中间

- 主体为该人物的立绘卡片列表/网格，卡片显示立绘缩略图和简短名称；支持新建、导入、AI 生成、替换、删除和拖动重排。
- 第一张立绘就是默认立绘，显示紧凑的默认标记；不再单独保存可与列表顺序冲突的 defaultPose 选择。
- 重排完成后头像和缺省 show 使用新第一张；脚本显式 pose 引用稳定 ID，不随排序变化。
- 选中卡片后，右栏展示这张立绘的预览及属性。中间不再常驻完整舞台和第二套中心点编辑器。
- 常见表情以独立立绘版本保存，名称如平静、开心、生气、惊讶、难过、害羞，允许自定义。

### 右侧

- 上方保留紧凑的人物属性：显示名称、稳定 ID、姓名颜色。
- 选中立绘后，下方为该立绘预览与属性：名称、稳定 ID、素材、脸部中心、裁切范围、校准缩放和翻转。
- 脸部中心建议落在鼻尖或两眼之间偏下的稳定面部位置；采用项目内一致的标记习惯，不要求精确的人脸关键点。
- 预览中直接拖动十字标记调整中心点；同一处提供坐标和裁切缩放控件，并同步展示头像裁切框。所有中心点调整都在这里完成。
- faceCenter 以未裁切原始图片左上角为原点，保存归一化 u/v 坐标；使用纹理裁边或图集时必须映射回原图坐标。
- 每张立绘保存自己的脸部中心和裁切范围，以适应构图差异；人物头像始终由第一张立绘派生，不生成独立头像源文件。
- 切换立绘时可将脸部中心对齐舞台上的同一参考位置，减少表情切换跳动；透明留白、图片尺寸不同也不能直接按矩形中心对齐。
- 脸部中心不是强制旋转轴。运行时渲染锚点与演出旋转轴由适配器计算或演出配置决定，普通用户只调整脸部中心和校准尺寸。
- 未校准时使用临时默认点并显示必要的校准状态，不把图片几何中心假称为已识别脸部。
- 高级资源入口：在兼容桥接可用时绑定 Prefab、骨骼动画或动画片段。
- 人物资料与舞台演出参数明确区分：这里修改的是资源默认值，脚本中的位置和缩放可以覆盖默认值。
- 已显式写入脚本的参数不随默认值变化；重命名显示名称不改稳定 ID。

### AI 生成立绘

- 中间工具栏与卡片操作中提供 AI 生成；选中立绘时默认以它为参考，否则使用第一张立绘。
- 弹框只保留参考图、表情选择/自定义要求、可编辑提示词，以及“交给 Agent”“复制提示词”。
- 提示词要求保留人物身份、发型服装、姿势、镜头、画布和构图，只修改指定表情；优先独立透明背景图片，避免把多个表情拼成一张不可直接使用的图。
- 常见表情可多选，生成任务明确期望输出数量；不假定所有 host 支持一次批量输出。
- 通过显式 host adapter 能力发现，判断是否支持发起/续接对话、传参考图、调用图像生成与结果回传；不能因网页嵌入某个 host 就假定存在通用 JS bridge。
- “交给 Agent”在适配器可用时提交包含 requestId、人物/参考立绘 ID、项目版本、提示词、期望素材清单的请求，让宿主发起或填入相应创作对话；发送与仅填入是不同能力，UI 如实反映。
- 没有接入或请求未被接收时，保留弹框与可复制提示词，允许手动附参考图、生成后拖入结果；复制成功不显示为生成成功。
- 结果先作为候选立绘展示，用户选择加入；沿用当前参考图校准可作为初值，但需要检查脸部位置。新结果不自动替换已有立绘或改变第一张。
- 任务状态至少区分待接收、已接收、生成中、待导入、完成、失败/取消；超时不重复发送，防止重复付费或重复生成。
- Skill 在宿主允许的图像工具中执行实际生成并导入素材。具体豆包工作办公等 host 的接入协议待验证，此处是自有适配器设计，不是已验证的宿主接口。

## 5. 背景

### 左侧

- 背景缩略图与名称，顶部新建/导入、搜索；支持复制、删除与引用查看。
- 同一地点的白天、黄昏、夜晚可各自作为背景资源，显示名允许分组命名。

### 中间

- 显示游戏画幅与素材边界；拖动调整取景，缩放改变裁切。
- 支持填满、适应、原尺寸，快速切换横竖画幅检查。
- 使用同一个 Cocos 渲染组件试听淡入、擦除等转场；前后背景可选。
- 将来可接入可兼容的动态背景 Prefab，普通图片路径保持简单。

### 右侧

- 名称、稳定 ID、素材、图片 rect、转场；背景在画布中通过八向手柄缩放、平移并裁剪。
- 默认转场和持续时间；剧本可以逐次覆盖。
- 可选配套环境音，但通过显式设置决定是否随背景切换，避免隐含播放行为。
- 修改背景默认取景会影响未覆写该参数的场景；脚本显式参数保持优先。

## 6. 界面

这里指游戏中的开始、对话、暂停、存读档、设置、养成主界面及各种弹出 UI，编辑器本身的工具栏不在此编辑。

### 左侧

- 按界面列出开始、对话、暂停、存档、读档、设置、养成页面及自定义页面；弹窗使用紧凑图标区分。
- 选中界面后显示其控件层级；支持层级重排、可见性、锁定和搜索。
- 顶部新建页面/弹窗；可选常用模板，模板展开为可编辑控件，不是不可调整的黑盒。

### 中间

- 使用 Cocos 实际 UI 渲染，编辑器工具覆盖在画面上方；避免用 HTML/CSS 模拟一套导出后不同的游戏界面。
- 画布上方的紧凑“+”打开控件面板，搜索或拖入控件；不常驻一整栏控件说明。
- 点击选择、拖动移动、拉伸调整尺寸；提供锚点、吸附和对齐。
- 可切换分辨率、横竖屏与安全区域预览。
- 通过工具按钮切换样例对白、长对白、多选项等状态；这些状态不写入实际故事。
- 需要测试按钮行为时进入交互试听，避免拖动编辑时误触游戏操作。

### 右侧

- 按元素类型显示：布局、锚点、间距、字体、字号、颜色、背景图片、边框、状态样式。
- 文本、进度、可见性、可用性等可以绑定全局变量或无副作用表达式；滑条、开关、输入框可以显式双向绑定一个可写全局变量。
- 文本元素可绑定内置对白数据源，选项容器绑定当前选项；内置对白数据源属于只读 UI 适配数据，不是额外的脚本变量作用域。
- 按钮可配置 call 目标脚本/标签，也可执行开始、继续、存读档、uipopup、uiswitch、uiclose 等命名动作。
- UI call 的返回点是按钮事件；不会覆盖或吞掉底层剧情的等待位置。弹窗和事件调度详见脚本说明。
- 字体、颜色等共享样式可复用，局部属性可以覆写。
- Creator 扩展节点通过受支持的适配器显示可编辑属性；未提供适配器时保留节点并标识为扩展内容，避免丢弃。
- 初期覆盖 AVG 与养成常用元素和约束布局，复杂组件通过可组合模板扩展。

### 控件调研与范围

Cocos 提供按钮、文本输入、滑条、进度条、开关、布局与滚动等基础组件；Ren’Py 的 screen 系统覆盖文本/图片按钮、数值条、输入、视口、热点及拖放等。以下是基于这些能力整理的产品范围；组合控件需要本工具实现，不声称都是 Cocos 内置组件。

| 类别 | 拟支持控件 | 典型用途 |
| --- | --- | --- |
| 展示 | 文本、富文本、图片、面板、图标、分隔线 | 姓名、对白、金币、日期 |
| 点击 | 文字/图片按钮、透明热点、开关、单选组 | 操作、地图地点、设置 |
| 数值 | 水平/垂直/环形进度条、滑条、步进数值 | 体力、好感、经验、音量 |
| 输入 | 文本/数字输入框、下拉选择 | 姓名、数量、选项 |
| 布局 | 自由容器、横纵布局、网格、遮罩、滚动视图、分页、页签 | 背包、商店、属性面板 |
| AVG 组合 | 对白框、姓名框、选项列表、历史记录、快捷菜单、存档格 | 剧情、存读档 |
| 养成组合 | 属性行、角色卡、物品格、任务行、日程格、日历、地点热点、奖励面板 | 属性、活动、背包、任务 |
| 反馈/弹出 | 确认框、提示浮层、气泡提示、通知、倒计时显示 | 确认、说明、冷却 |
| 后续增强 | 拖放区域、排序列表、可复用自定义控件 | 配装、道具拖放、复杂日程 |

首轮优先落实基础控件及对白、选项、属性条、物品格等高频组合。物品格/日程格可先绑定具体全局字段；大规模动态集合与通用循环模板另行扩展，不隐式引入局部变量或任意可执行模板。

### 数据绑定与行为

- 示例：正文 `体力 {attr.health}/{attr.maxHealth}`；进度值 `attr.health`；最大值 `attr.maxHealth`；训练按钮可用条件 `attr.health >= 10`。
- 绑定选择器与表达式补全使用同一份全局变量树，支持 attr.health 一类用户命名的层级字段。
- 默认单向读取。双向绑定只能指向具体可写变量，不能向计算表达式写入；输入提交时按类型、上下限校验。
- 数值条显示按范围归一化并钳制，显示钳制不修改源变量；非法最大值在编辑器提示。
- 全局变量改变后按依赖刷新；程序同步控件值不再次触发用户 change/click 事件，避免绑定循环。
- 按钮调用动作可以选择在调用前或返回后关闭当前弹窗；动作顺序在属性面板明确显示，不藏在脚本调用副作用里。
- 事件正在执行时禁用重复提交；不同事件按运行时顺序调度，防止两个训练调用同时扣费。
- 编辑画布使用可重置的测试数据，交互试听不写回项目变量默认值。

### 页面与弹窗

- uiswitch 替换基础页面；uipopup 在其上叠加弹窗；uiclose 关闭弹窗。三者是独立能力，脚本和按钮共用动作协议。
- 弹窗默认模态，拦截底层输入；遮罩点击关闭、返回键关闭、暂停舞台动画/音频分别配置。
- 模态不等于冻结整个运行时：弹窗动画、绑定和按钮脚本仍然能执行。剧情与按钮脚本各自按阻断式语义执行，同一时刻只有一个脚本执行链获得调度权。
- 保留独立对白呈现通道与 UI 模板，页面切换不丢失当前对白或待选项；UI 事件中的对白临时接管呈现，返回后恢复原待交互数据。
- 弹窗打开/关闭有稳定实例和生命周期，嵌套弹窗按栈关闭，关闭后恢复焦点；取消或失败也要解除对应等待。

## 7. 项目设置

作为“界面”和“预览”之间的独立 switcher 页面。左侧为设置分类，中间为主要表单；右侧可用小画幅预览显示结果，不为简单设置强行添加重复属性栏。

- 基础：项目名称、默认语言等实际需要的项目字段。
- 画面：竖屏/横屏切换、参考尺寸、画面适配方式与安全区。
- 变量：按层级树管理全局变量、类型和默认值；预览中的临时值与这里的默认值分离。
- 运行与导出：入口只读显示为剧本第一项、默认界面、结束行为、实际可用的构建目标配置。

默认竖屏，建议参考尺寸为 720×1280。配置存储方向及短边/长边参考尺寸，运行时推导宽高，避免方向与宽高互相矛盾；切横屏得到 1280×720。尺寸是设计建议，可修改，不是输出设备的硬编码分辨率。

- 切换方向后，界面画布、背景取景、人物演出位置和预览画幅同步更新；新测试与导出采用新设置。
- 已有运行会话保持原配置快照，重启后应用新设置。
- UI 使用锚点、布局容器和安全区约束适配；必要时为同一界面添加横/竖屏布局覆写，共用控件 ID、绑定和事件。
- 不自动旋转图片或改写剧本文本；人物脸部归一化中心不受方向变化影响。
- 背景采用相对画幅的图片 rect；同一立绘舞台位置预设按画幅重新计算，脚本显式坐标仍是参考画幅坐标。
- 实际浏览器或设备尺寸与参考比例不同时默认等比适配并留边，不拉伸；平台支持时应用方向设置，不支持强制锁定时仍按同一游戏画幅呈现。
- 缺少特定方向的布局覆写时使用通用约束布局，编辑器提示溢出/遮挡，不擅自删掉控件。

## 8. 预览

左侧为实际游戏，可点击推进、选择、使用游戏菜单。顶部公共播放/停止管理会话，局部控制提供暂停和单步；暂停冻结剧情调度、动画与音频的测试时钟。

右侧为紧凑调试栏，按需展开：

| 区域 | 内容与操作 |
| --- | --- |
| 入口 | 本次入口脚本、测试预设、重新开始 |
| 变量 | 名称、类型、当前值；搜索、直接修改 |
| 执行 | 当前脚本/行、运行或等待状态；点击回源码 |
| 调用栈 | 当前调用帧、来源位置、UI 事件与等待链 |
| 舞台 | 当前背景、角色立绘与可选参数 |
| 问题 | 本次运行的错误与相关源码位置 |

- 全局变量按可折叠层级树展示，可搜索和直接修改；类型校验失败不写入。内置调试状态只读且不属于脚本变量。
- 在指令边界应用变量修改；阻塞于对白/选项时该位置也是可调试边界。第一版不存在局部变量面板。
- 选项条件在展示和确认时重新检查；修改变量后刷新选项，不自动选择。
- 修改只影响当前会话；另有明确动作“存为测试预设”，不会改变项目默认值。
- 重新开始使用默认值或选定预设，不保留上次临时修改。
- 调试器默认只在创作环境出现，发布版不包含变量编辑面板。
- 运行会话绑定代码与资源版本。编辑后显示可重启状态；第一版不对运行中的调用栈做源码热替换。
- 界面试听可观察绑定刷新、按钮 call 与弹窗等待链；AI 生成请求不进入游戏预览运行时。
- 后续如实现“从光标预览”，应使用快照/流程重放及可明确选择的分支，不能把直接执行当前位置当作完整上下文恢复。

## 9. 可运行导出与 Creator 工程

### 9.1 优先级

主要交付是可运行游戏，Creator 工程作为正式的继续开发出口。

| 目标 | 定义 |
| --- | --- |
| Web | 可部署的游戏目录/压缩包，与内嵌预览共用 AVG 运行时 |
| 桌面、移动、小游戏 | 对应平台的构建适配器，按实际已验证的平台逐项开放 |
| Cocos Creator 工程 | 指定 Creator 版本可打开、预览、继续开发和构建的源工程 |

导出面板按可用能力显示目标；平台工具链缺失时给出具体缺项。初期优先验证 Web 与 Creator 工程，其他可运行平台逐项实现。Web 默认承诺通过 HTTP(S) 部署运行，不把双击 file:// 等同于完整兼容。

### 9.2 Creator 工程内容

- 固定并记录匹配的 Creator/engine 版本、AVG 运行时版本和项目数据版本。
- 启动场景，包含 AVG 启动与加载组件。
- AVG TypeScript 运行时、脚本源文件、编译结果与项目清单。
- 人物、背景、音频、字体，以及项目管理的 .meta 和 UUID 映射。
- 可在 Creator 编辑的界面 Prefab、舞台组件和演出资源。
- 构建配置与独立的用户扩展目录。
- 不包含可再生的 library、temp 等缓存目录，也不把编辑器 Web 应用打包为游戏依赖。

采用经过目标 Creator 版本验证的工程模板与资源生成流程。使用 cocos-engine 并不会自动生成 Creator 工程；场景、Prefab、导入元数据和资源引用需要导出适配器负责。

### 9.3 使用 Creator 生态资源

分层接入：

1. 图片、音频、字体：作为基础资源导入，按实际支持格式使用。
2. Prefab、动画、骨骼资源、材质等：通过匹配版本的 Creator 导入/构建流程处理，再通过 AVG 资源适配器绑定。
3. 自定义组件：通过显式的组件和指令注册接口接入。
4. 原生插件及依赖平台 API 的资源：受对应构建平台约束，不能假定浏览器预览可运行。

预览可加载匹配版本预构建的资源 Bundle；不假设浏览器能直接解释任意原始 .prefab、.scene 或原生组件。依赖、导入设置和 UUID 要与资源一起保留。平台不支持的内容在预览/构建前诊断。

### 9.4 再导出与回流

- 第一版 Creator 导出为可独立继续开发的工程快照，不承诺任意 Creator 修改能反向转成轻量编辑器数据。
- 生成内容与用户扩展目录有明确归属。重新导出默认到新目录；显式更新已有导出时检查生成文件是否被用户修改，不能静默覆盖。
- 后续可对受支持的界面 Prefab、资源绑定提供受限回流；任意自定义组件不在自动回流保证范围。
- Skill 中应说明哪些修改适合轻量编辑器，哪些需要交给 Creator。

## 10. 示例项目

《最后一张节目单》：校园文化节前，一个班的节目被撤下。负责提交的陈默受到怀疑，要求公开记录的林夏尚不知道其中涉及另一位同学的隐私。玩家在维护朋友、查证与公开之间作选择。

约 5—8 分钟，3 名主要人物、3 个背景、2 次关键选择、3 个短结局。使用普通公开功能展示对白、立绘、转场、动画、变量、条件与音效。以 main 调用可返回的调查片段，再 jump 到结局，演示两类流程控制的区别。

## 11. 首轮实现验证

1. 工程模板中的 Cocos 播放器加载外部 AVG 数据，跑通一个最小故事。
2. 同一故事在 Web 预览、Web 导出、Creator 工程中表现一致；重开工程资源引用不丢失。
3. 验证入口重排、跨脚本 jump、嵌套 call/return、变量调试和停止时清理。
4. 再扩展人物/背景/界面编辑与资源桥接；平台构建逐项验证。
5. 验证 while 中的对白/动作逐项等待，按钮 call 不丢失底层等待位置，关闭弹窗后正确恢复。
6. 默认竖屏，切横屏后 Web 预览和导出布局一致；检查两种方向的溢出、安全区和背景裁切。

## 界面设计与半身素材更新

界面页使用静态 DOM 画布设计布局，不创建游戏引擎、不触发按钮事件和视听效果。八类控件从工具栏展开添加；选择、拖动、缩放对话框或控件，中心吸附，方向键按参考画布 1 像素微调（Shift 为 10 像素），Alt 拖动关闭吸附。绑定值以项目默认值展示。完整效果在预览页运行。

默认人物素材为腰部以上半身 PNG，pose.framing 为 bust。faceCenter 仍是原始图像鼻子附近的归一化坐标，头像由第一张立绘裁切；旧全身素材使用 full。project.theme 定义 paper、panel、ink、accent；默认游戏采用纸纹、细金边与姓名牌。
