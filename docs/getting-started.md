# 快速入门

从一段校园故事开始，改一句对白，再把它玩出来。你可以自己操作编辑器，也可以随时让豆包工作帮忙。

## 1. 告诉豆包工作安装

在豆包工作中新建对话，把下面这句话发给它：

```prompt
使用 wangyu.tech/avg/skill.zip 安装豆剧场，帮我创建一个文字冒险游戏项目，并打开编辑器。
```

等它完成准备后，打开它提供的编辑器预览。第一次会看到《最后一张节目单》：文化节前一天，一个节目从名单上消失了，你要决定先听解释，还是公开记录。

![豆包工作协作示意：左边向豆包工作描述想法，右边直接编辑作品](../assets/docs/doubao-desktop.jpg)

上图展示协作方式，右侧为真实编辑器截图；豆包工作的实际窗口和按钮位置以你使用的版本为准。

如果豆包工作还没有打开画面，可以继续说：

```prompt
请打开刚才这个作品的编辑器，让我先玩一下内置示例。
```

准备环境、创建作品和打开预览的工作交给豆包工作。编辑器已包含在工具包里，你不需要输入终端命令，也不需要安装 Cocos Creator。

## 2. 认识编辑器

![编辑器导览：左边选剧本，中间写故事，右边添加或修改演出](../assets/docs/script.jpg)

| 位置 | 可以做什么 |
| --- | --- |
| 顶部页面 | 在剧本、人物、背景、音视频、界面、项目设置和预览之间切换。 |
| 左边列表 | 选择要编辑的剧本、人物或页面；加号用于新建。 |
| 中间区域 | 写对白、查看立绘，或在画布上摆放图片和控件。 |
| 右边属性 | 改名称、挑选素材、设置演出，调整选中对象的样式。 |
| 右上角 | 三角形开始预览，方形停止预览，“导出”带走游戏。 |

界面较窄时，用中间工具栏两侧的按钮展开列表或属性。修改会自动保存；离开前确认底部显示“已保存”。

## 3. 改第一句对白

1. 选择“剧本”，在左边打开“放学后”。
2. 找到“节目单上为什么没有我们班？”，只修改冒号后面的文字，例如“等一下，我们的节目去哪了？”
3. 点击右上角三角形，进入预览。等开场旁白结束后点击画面，看看自己的新对白。

文字会逐字出现。第一次点击可以让当前句完整显示，再点一次进入下一句。故事给出选项时，直接点你想选的那一项。

不确定怎么改，也可以直接告诉豆包工作：

```prompt
把林夏的开场对白改得更委屈一点，保留原来的情节和后续选择。
```

## 4. 玩一遍，再调整

![预览页面：左侧游玩，右侧查看并调整本次测试的数值](../assets/docs/preview.jpg)

在“预览”中按玩家的方式走一遍故事。点击游戏顶部“历史”可以回看对白；暂停菜单里也能找到它。想重新开始时，先停止，再点击播放。

右边的数值只影响这一次测试。例如切换是否找到证据，可以检查不同选择是否出现。第一遍只要顺着故事玩，不必先学会所有设置。

## 5. 导出你的游戏

![导出窗口中选择 Web 游戏，再生成和下载](../assets/docs/export.jpg)

1. 点击右上角“导出”。
2. 点击“Web 游戏”，等待打包完成。
3. 点击弹窗下方出现的文件名链接下载，保存到容易找到的位置。

要让别人通过链接游玩，可以继续告诉豆包工作：

```prompt
请把刚才导出的网页版游戏准备成可分享的网页，先让我确认访问方式和发布位置。
```

交给懂开发的朋友继续制作，可以选“Cocos Creator 工程”。需要微信或抖音小游戏时，直接告诉豆包工作目标平台，让它使用对应的小游戏工具包。

下载游戏包后仍保留原作品，日后在原作品中继续修改。详细步骤见[导出与分享](export-guide.md)。
