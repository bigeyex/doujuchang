# 导出与分享

导出把当前作品整理成游戏包。修改后可以重新导出，原作品仍然保留。

## 导出网页版游戏

![选择 Web 游戏，再生成和下载](../assets/docs/export.jpg)

1. 在“预览”里检查主要流程。
2. 点击“导出”，再点击“Web 游戏”，开始打包。
3. 等待完成，点击弹窗下方出现的文件名链接下载。
4. 选一个容易找到的位置保存。

![打包完成后，点击弹窗下方的文件名链接下载](../assets/docs/export-ready.jpg)

下载后，要通过浏览器游玩或分享链接，可以交给豆包工作准备：

```prompt
请帮我打开刚导出的网页版游戏，并告诉我怎样分享给朋友。需要发布到外部网站时，先让我确认。
```

不要只双击包里的网页文件判断是否正常。让豆包工作按网页游戏的方式打开，再检查图片、音乐、存读档和横竖屏。

## 导出微信或抖音小游戏

在“导出”窗口点击“微信小游戏”或“抖音小游戏”，填写自己的 AppID（可选），再点击导出。首次使用会自动下载组件，之后可复用缓存。也可以告诉豆包工作目标平台：

```prompt
请使用 wangyu.tech/avg/kit-minigames.zip，把这个作品导出为微信小游戏，并告诉我接下来需要提供什么。
```

需要抖音版本时，将平台改为“抖音小游戏”。之后需要自己的平台账号，在对应开发者工具中检查、预览和提交。导出完成不等于已经发布，上传与发布前应再确认。

小游戏对包大小有要求。视频、长音频或大量高清图片可能需要精简，豆包工作可以根据导出报告帮你定位。

## 交给开发者继续制作

点击“Cocos Creator”开始打包，完成后下载工程。使用 Cocos Creator 的开发者可以继续增加玩法或制作其他平台版本。

只需要做故事和网页版游戏时，不必安装 Cocos Creator。

## 保留可以继续编辑的作品

游戏包用来玩，原作品用来继续修改。备份或换电脑时，可以这样说：

```prompt
请把这个作品完整备份，包括剧本、人物、背景、音视频、界面和设置，并告诉我备份放在哪里。
```

分享给朋友继续创作时，交给对方完整作品。重新打开后先检查素材是否齐全，再继续编辑。
