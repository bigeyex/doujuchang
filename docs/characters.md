# 人物与立绘

“人物”管理角色名字、半身立绘和不同表情。先选人物，再选一张立绘，在右侧调整。

![中间是人物的表情列表，右边校准所选立绘](../assets/docs/characters.jpg)

## 添加人物和表情

1. 打开“人物”，点击左侧列表上方的加号。
2. 填写人物名称，按需选择姓名颜色。
3. 点击“导入立绘”，选择准备好的图片。
4. 继续导入其他表情，分别命名为“平静”“生气”“惊讶”等。

建议使用透明背景的半身图片，只保留头部和上半身。各个表情尽量使用相同画布、姿势和人物大小，切换时更自然。

第一张是默认立绘。人物头像也从这张图的脸部裁切，不需要另外准备头像图片。

## 校准脸部中心

选中一张立绘后，右侧显示它的图片。点击脸部中心，通常是鼻子附近，再根据头像效果调整裁切范围。

每张表情都校准到相同的脸部位置。若切换时忽高忽低，先检查中心点和图片大小，再适当调整校准缩放。半身素材选择“半身”构图；旧全身图片才选择“全身”。

要换掉当前表情的图片，点击紧挨预览图的“替换图片”，然后重新检查脸部中心。

## 用 AI 生成表情

![选择表情后，可以复制提示词或交给 Agent](../assets/docs/character-ai.jpg)

1. 选中一张参考立绘，点击“AI 生成”。
2. 选择想增加的表情，需要时补充要求。
3. 当前宿主已接入生成能力时，点击“交给 Agent”；也可点“复制提示词”，发给图片工具。
4. 生成后导入图片，检查透明背景、人物身份和脸部对齐。

一次生成一张表情，不要拼成大图。可以这样告诉豆包工作：

```prompt
以当前林夏立绘为参考，生成“惊讶”表情。保持人物、校服、发型、姿势、画布和半身构图不变，只改变表情，输出透明背景图片。
```

提交请求后仍需等待实际生成结果。没有自动启动生成时，直接把提示词发到豆包工作对话中继续处理。

## 让人物出现在故事里

返回“剧本”，点击“立绘”，选择人物、表情、位置和显示方式。每个角色在画面上只保留一张立绘，重复显示会更新旧图。

想让两个人都站在左侧，给他们选择不同槽位。选择“隐藏”时默认清空所有立绘，也可以只隐藏一个人物。
