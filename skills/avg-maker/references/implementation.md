# 首版实现与验证

版本 0.1.0，Cocos Creator / cocos-engine 3.8.8，Node.js 22。

## 已实现

引擎随 skill 分发：预览、Web 导出和 Creator 工程生成均不依赖本机安装 Creator；参见 runtime-distribution.md。

- 可安装、可打包的 avg-maker skill；启动、创建、检查、导出、AI 请求查询与结果导入命令。
- 剧本、人物、背景、音视频、界面、项目设置、预览七个编辑器页面。
- CodeMirror 编辑器：语法高亮、自动补全、查找替换、折叠、撤销重做；参数确认后插入、标签表单、选项列表增删排序与人物快捷对白。
- 剧本重排与首项 main、列表快速预览。
- 默认三张半身立绘（腰部以上）、透明 PNG、framing 构图属性；纸色/细金线游戏主题与生成的纸纹素材。
- 立绘卡片列表、导入与重排、第一张默认、基于脸部中心裁切的头像、统一的中心点校准。
- AI 立绘提示词、常用表情选择、复制、宿主桥接探测与项目内的待处理请求。CLI 可追加生成结果。
- 背景图片平移、八向缩放、画布缩放、画幅裁剪，不再暴露焦点字段。
- 独立静态界面设计画布；八类控件在工具栏展开，支持控件/对话框拖动、缩放、中心吸附、对齐、方向键微调、撤销、缩放画布，以及文字、颜色、绑定和事件配置。界面页不加载游戏引擎，不执行按钮事件；完整交互保留在预览页。
- 文本、图片、面板、按钮、进度条、滑条、开关、输入框和可滚动对话历史；图片状态样式、对白背景/姓名/文本可分别设计。
- 竖屏半身立绘按画幅宽度缩放、左右分开；默认对白框横向满幅并贴底，文本左上起笔逐字显示，完成后右下方浮动向下箭头；点击一次补全，再点推进。
- 默认竖屏、项目设置切横屏；预览和导出共用参考尺寸，游戏画幅裁切。
- 全局变量与层级路径、表达式、if/elif/else、while/break/continue、jump、嵌套 call/return。
- 多行块注释、位置/槽位立绘替换、对白/选项变量插值、阻断式 MP4 视频、对白、演出、音效、弹窗，背景音乐启动/淡变；文本打字、速度、停顿与基础行内格式。
- UI popup/switch/close、按钮 call、父剧情等待恢复、变量调试、暂停/单步。
- 稳定交互位置存读档；源码指纹不符时拒绝旧存档。
- v2 项目空间：入口索引、分类 JSON 配置、有序剧本清单、标签正文、分类素材、JSON Schema 和项目内 exports；兼容旧 v1。自动保存、跨配置外部修改检测和版本冲突提示。

## 当前边界

- 可运行导出已实现 Web；Windows/Android/iOS 等需要在导出的 Creator 工程中配置相应工具链并构建，首版不提供已验证的一键原生构建入口。微信/抖音小游戏可用独立 kit-minigames.zip 及预编译播放器导出，已验证导出结构和分包预算；开发者工具/真机与平台视频差异仍需目标设备验证。
- Cocos Creator 工程输出为快照。基础 UI Prefab 的位置、尺寸、文字、字体与文本颜色会在工程内运行时读取；任意 Creator 编辑回流到 Web 编辑器、任意第三方组件自动转化尚未实现。
- 养成项目可以组合基础控件与全局变量；通用背包/日历/任务/拖放/动态集合模板尚未提供成品控件。
- 豆包工作办公等宿主没有在本次环境中验证的自动发起对话协议。默认提供提示词复制和可由 Agent 处理的请求文件；不能把请求已保存解释为已经生成图片。
- 剧本目标目前为静态目标，存档使用保守的完整源码指纹，不提供跨脚本版本自动迁移。
- 原始设计中尚未落实的快照重放到光标、方向专用布局覆写、面板拖动调宽等保留为后续设计，不在首版界面中提供无效入口。
