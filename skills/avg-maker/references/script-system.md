# 详细脚本格式

剧本为 UTF-8 文本，每条结构指令独占一行。中文是默认写法，兼容英文标签、参数和枚举，同一文件可以混用。人物、资源、剧本和变量使用配置中的稳定 ID，不根据显示名称自动查找。

## 文件、入口与目标

`scripts/index.json` 是有序剧本清单，第一项为游戏入口。重排不改变脚本 ID；文件不按列表顺序自动串联。普通文件结尾相当于返回：有调用者时返回，否则结束。

| 目标 | 解释 |
| --- | --- |
| `investigate` | ID 为 investigate 的脚本开头。 |
| `#records` | 当前脚本中 ID 为 records 的标签。 |
| `ending#public` | ending 脚本的 public 标签。 |

脚本和标签名支持 Unicode 字母、数字、下划线、短横线；不要使用空白、井号或方括号。标签声明位于脚本顶层，不能跳入条件、循环或选项块中部。

## 对白与多行文本

非空普通文本行是一句旁白。`人物ID: 文本` 是人物对白，显示名称取自人物配置；未知人物会报错。空行不产生等待。

```avg
雨停了，走廊里还留着潮气。
lin: 节目单上为什么没有我们班？
chen: 我也在等一个解释。
```

多行单句使用“对白”，可省略人物成为旁白。只把关闭标签识别为块结束，块内仍支持插值和行内格式。

```avg
[对白 lin]
我想再问你一次。
这真的是你自己的决定吗？
[/对白]
```

打字机未完成时点击先显示整句，下一次确认再推进。对白显示后会记录当时姓名、插值后的纯文本和源位置，后续变量变化不改写旧历史。

## 标签、参数与引号

基本形式为 `[指令 位置参数 命名参数=值]`。每条指令只接受规定字段，不接受重复参数；中英文指向同一字段也算重复。

```avg
[背景 hall_evening 转场=淡入淡出 时长=0.4]
[显示 lin 表情=angry 位置=左侧 槽位=0]
[选项 文本="Check the records" 目标=ending#public]
```

裸值按字面量处理。中文短文本、资源 ID、路径和带井号目标通常不需要引号；含空白、方括号、花括号、双引号、等号、反斜杠或注释起始符的值使用 JSON 双引号字符串。数字和英文布尔裸值会解析为相应类型。

普通资源参数不会因为它恰好也是变量名而隐式取值。需要表达式时使用花括号；例如 `表情={currentPose}`。人物 ID 与流程目标使用静态引用。

条件、循环和赋值直接读取标签名后面的表达式，不需要额外花括号：

```avg
[如果 evidence 且 attr.health >= 10]
  [设置 trust += 1]
[/如果]
```

选项的“条件”本来就是表达式字段；多词表达式仍用花括号确定参数边界：

```avg
[选项 文本=公开记录 目标=ending#public 条件=evidence]
[选项 文本=参加训练 目标=training 条件={attr.health >= 10 且 非 evidence}]
```

## 全局变量与表达式

只有全局变量；先在变量配置中声明类型与默认值，赋值不会隐式创建新变量。点分路径可以组织属性，例如 `attr.health`，但不能同时声明叶节点 `attr` 和 `attr.health`。

变量段以 Unicode 字母或下划线开始，后续可以包含字母、数字、下划线。保留词 true、false、and、or、not、真、假、且、或、非，以及原型相关名称不能用作变量段。路径不支持动态下标、对象反射或函数调用。

| 运算 | 写法 |
| --- | --- |
| 布尔 | `真` / `假`，兼容 `true` / `false`。 |
| 逻辑 | `且` / `或` / `非`，兼容 `and` / `or` / `not`。 |
| 算术 | `+ - * / %`、一元负号。 |
| 比较 | `== != < <= > >=`。 |
| 分组 | 圆括号。 |
| 字符串 | 单引号或双引号字符串。 |

算术和大小比较要求有限数字；逻辑与条件要求布尔；等值比较要求类型一致。除零、未知变量和类型不符报错。逻辑词之间使用空格，且/或短路求值。

优先级从高到低：括号、一元负号、乘除取余、加减、大小比较、等值比较、非、且、或。`非 trust > 0` 等于 `非 (trust > 0)`。连续比较请拆成两个条件。

赋值支持 `= += -= *= /=`，复合赋值只接受数字：

```avg
[设置 trust += 1]
[设置 attr.health -= 10]
[设置 evidence = 真]
[设置 playerName = "林夏"]
```

## 插值、行内样式与注释

对白和选项文字支持 `{变量}` 或 `{表达式}`，在显示时求值。插值结果按文字呈现，不会再被解释成标签。

```avg
lin: {playerName}，你现在的体力是 {attr.health}。
```

对白支持以下行内格式：

| 行内格式 | 含义 |
| --- | --- |
| `[加粗]文字[/加粗]` | 加粗，兼容 b。 |
| `[斜体]文字[/斜体]` | 斜体，兼容 i。 |
| `[颜色 #ffcc66]文字[/颜色]` | 六位十六进制颜色，兼容 color。 |
| `[速度 10]文字[/速度]` | 每秒字符数，范围大于 0 且不超过 1000，兼容 speed。 |
| `[停顿 0.3]` | 在后续文字前停顿对应秒数，兼容 pause。 |

样式和速度标签需要正确配对，范围限于一句文本。多行对白块仍属于一句。

独占行 `//` 为单行注释，`/* ... */` 可跨行或出现在参数之间，不支持嵌套。字符串内的注释符保留字面值。注释不改变后续诊断行号。

```avg
/* 暂时停用这一小段
[显示 lin 位置=左侧]
*/
[背景 radio /* 广播室 */ 转场=淡入淡出]
```

正文用反斜杠转义方括号、花括号、冒号、反斜杠与斜杠。例如 `\{trust\}` 显示字面的花括号，`时间\: 17:00` 避免把前缀识别成人物。未知转义报错。

## 条件与循环

```avg
[如果 evidence]
  lin: 我们有记录可以核对。
[否则如果 trust >= 2]
  lin: 我愿意再相信你一次。
[否则]
  lin: 先别急着下结论。
[/如果]
```

否则如果可以有多个，否则最多一个且必须在最后。条件必须求得布尔值。

```avg
[循环 attr.health >= 10]
  lin: 再练一次。
  [设置 attr.health -= 10]
  [如果 attr.health == 10]
    [跳出]
  [/如果]
[/循环]
```

循环每次重新检查条件；“跳出”退出最近一层循环，“继续”重新检查该层条件。它们只出现在循环中。循环可嵌套，但应能结束或产生等待；连续计算超限会报错，避免冻结页面。

## 跳转、调用与结束

| 指令 | 行为 |
| --- | --- |
| `[标签 records]` | 声明当前脚本顶层位置。 |
| `[跳转 #records]` | 转移，不添加返回点。 |
| `[调用 investigate]` | 保存返回点并执行目标脚本。 |
| `[返回]` | 恢复最近的调用者。 |
| `[结束]` | 结束整局故事，清空当前等待与调用。 |

调用共享全局变量和舞台，不提供局部变量、调用参数或返回值。返回不撤销变量与画面修改。入口直接返回会报错；独立快速预览允许返回并结束测试。

标签不会自行阻止顺序执行；将子流程放在主流程后面时，用结束或跳转隔开，避免跌入。

## 选择与选项

```avg
[选择 后备目标=#no_choices]
  [选项 文本=公开记录 目标=ending#public 条件=evidence 不可用=禁用]
  [选项 文本="先听解释（信任 {trust}）" 目标=#listen]
[/选择]
```

选择块只包含选项、空行和注释。选项必填文本与目标；“条件”可选，缺省为真。“不可用”缺省隐藏，禁用则保留不可点击的选项。显示和确认时会检查条件，测试变量改变后刷新选项。

选中后按跳转语义进入目标。需要调用时，让选项先跳到标签，再调用子流程。没有启用选项时，使用选择块的后备目标；未设置则报错。

选项的目标为静态引用，文本支持插值。也可使用显式文本表达式，如 `文本={playerName}`。

## 背景、立绘与动画

| 指令 | 必填 | 可选参数 |
| --- | --- | --- |
| 背景 | 资源(id) | 转场、时长。 |
| 显示 | 人物(character) | 表情、位置、槽位、方式、横坐标、纵坐标、缩放、翻转、转场、时长。 |
| 隐藏 | 无 | 目标人物、转场、时长。 |
| 动画 | 目标人物、动画预设 | 时长。 |
| 等待 | 无 | 时长；省略则等待一次确认。 |

显示缺省使用人物第一张立绘、中央位置和 0 号槽位。一个人物只能显示一张，重复显示先移除该人物旧图。相同位置与槽位替换；其他槽位保留。方式为增加且省略槽位时，选择该位置最小的空槽位。槽位是非负整数，没有独立的实例属性。

```avg
[显示 lin 位置=左侧]
[显示 chen 位置=左侧 槽位=1]
[显示 lin 表情=angry 位置=右侧]
[隐藏 chen]
[隐藏]
```

隐藏不指定人物时清空所有立绘。动画预设有抖动、点头、跳跃、练习、淡入淡出，目标使用人物 ID。横纵坐标按参考画幅中心原点、横向右/纵向上计算，单位为设计像素，可逐轴覆盖预设位置。

动作按演出完成顺序执行，时长非负。`[等待 时长=1]` 等一秒，`[等待]` 等待点击确认。普通演出没有通用的后台执行开关。

## 音乐、音效与视频

| 指令 | 参数 | 等待 |
| --- | --- | --- |
| `[音乐 campus]` | 资源必填，动作默认播放，可设置音量、淡变时长。 | 启动完成后继续，背景音乐循环播放。 |
| `[音乐 动作=停止]` | 停止时不要求资源。 | 停止动作完成。 |
| `[音效 bell]` | 资源必填，音量可选。 | 播放结束。 |
| `[视频 opening 允许跳过=真]` | MP4 资源必填，音量与允许跳过可选。 | 视频结束或允许的跳过。 |

音量范围 0–1。资源先登记到音视频配置；省略音量时使用资源设置。视频按比例显示，暂停与停止跟随游戏会话。平台编码支持应在目标环境验证。

## 页面与按钮调用

| 指令 | 行为 |
| --- | --- |
| `[弹窗 attributes]` | 打开指定页面，并等待关闭。 |
| `[切换界面 game]` | 切换基础页面，不自动结束故事。 |
| `[关闭弹窗]` | 关闭当前按钮任务所属弹窗，没有所属弹窗时关闭栈顶。 |
| `[关闭弹窗 attributes]` | 关闭指定弹窗，以及它上方的子弹窗。 |

同一弹窗不能重复打开。按钮可以调用脚本；调用期间保留父剧情的执行位置与等待，返回后恢复。按钮调用中的对白、选项和演出仍然按顺序等待。返回不等于关闭弹窗，需要明确关闭动作。

例如属性页的训练按钮调用 training，training 自行检查体力，然后关闭所属弹窗并返回：

```avg
[如果 attr.health >= 10]
  [动画 lin 动画=练习 时长=0.6]
  [设置 attr.health -= 10]
  [设置 attr.study += 1]
[否则]
  lin: 先休息一下吧。
[/如果]
[关闭弹窗]
[返回]
```

文本、进度条和按钮条件使用同一套表达式。文本可插值，进度条配置 value/max；滑条、开关和输入框的 bind 指向已声明变量。字段结构见[项目结构](project-format.md)。

## 历史、存档与诊断

历史保存最近 1000 句，随存档恢复，新游戏清空。界面按钮使用 history 动作，或通过含 history 控件的弹窗显示。查看和关闭历史不会推进对白。

存档支持没有活动演出、没有嵌套按钮任务的稳定对白、选择、弹窗或点击等待位置。剧本文本或顺序改变后，旧存档会被判为不兼容，需要重新开始。

编译错误包含脚本和行号，例如未知资源、变量或目标、参数重复、块未闭合和错误的循环控制。运行错误包括类型不符、没有可选项、无对应调用的返回或连续计算超限。停止游戏会取消当前演出，旧回调不会继续推进新会话。

## 完整跨文件案例

以下使用内置示例的背景、人物、evidence 与 trust 变量。三个片段分别保存为对应 ID 的剧本，main 排在第一项。

main：

```avg
[背景 hall_evening]
[显示 lin 位置=左侧]
lin: 节目单上为什么没有我们班？
[调用 investigate]
[选择]
  [选项 文本=公开记录 目标=ending#public 条件=evidence]
  [选项 文本=先听解释 目标=ending#private]
[/选择]
```

investigate：

```avg
[显示 chen 位置=右侧]
chen: 提交记录在广播室的电脑上。
[设置 evidence = 真]
[返回]
```

ending：

```avg
[标签 public]
所有人都看到了记录，争执终于停下。
[结束]

[标签 private]
[设置 trust += 1]
lin: 先把事情查清楚，我们一起去广播室。
[结束]
```
